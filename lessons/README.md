## Adding the next one

```
mkdir 17-<topic-slug>
# build 17-<topic-slug>/index.html
# then add its row to the right category in index.html
```

Where a topic quotes a number, recompute it rather than repeating it, and chase
quotations to whoever actually said them. Every study page carries **Watch for**
boxes and a **To check** list marking the places that did not survive checking.

Study pages summarise and quote briefly. They never reproduce a lecture or a book
at length.
